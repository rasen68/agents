# Pi configuration

Contains four vibecoded extensions; I cannot guarantee anything about the code beyond this point.

`nav` combines `/cd`, Alt+j/k reasoning-level shortcuts, empty-search picker navigation, and an Alt+N `less`-style transcript viewer.

`pi-code-blocks` renders model \`\`\` code fences with `batcat` or `bat` syntax colors, line numbers, and borders.

`pi-goal-x` is a local fork of https://github.com/tmonk/pi-goal-x that replaces the infinite slash commands with a nice screen accessible with `Alt+g`.

`pi-parallel-sessions` is a local fork of https://github.com/liushihao456/pi-sessions that removes the parent-child hierarchy and gives `Alt+a` session picker plus automatic naming.
